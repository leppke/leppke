Stripe tranzakciók

stripe.com fiók lekérdezése
Add meg a Stripe API kulcsodat. Erősen ajánlott csak olvasásra jogosult restricted key-t (rk_...) használni — a Stripe Dashboardon: Developers → API keys → Create restricted key, olvasási joggal. A kulcsot csak ez a készülék tárolja.
A kulccsal a böngésző közvetlenül a Stripe-ot hívja (api.stripe.com), az adatok nem mennek át más szerveren.
